# Dra. Catherine Fuchs | Radiologia & Diagnóstico por Imagem

Landing page de alta conversão desenvolvida para a **Dra. Catherine Fuchs**, especialista em ultrassonografia para a Saúde da Mulher, Medicina Fetal e Mapeamento de Endometriose (Rio Verde / GO).

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com uma stack moderna focada em performance, SEO e experiência do usuário (UX):

- **Next.js** (React Framework com Server & Client Components)
- **CSS Modules** (Escopo isolado de estilos e design modular)
- **Glassmorphism Design** (Efeitos visuais translúcidos com suporte a `backdrop-filter`)
- **JavaScript (ES6+)**
- **Vercel** (Deploy e preview contínuo)

---

## ✨ Principais Funcionalidades

- **Design System Exclusivo:** Paleta de cores baseada em tons de ameixa/roxo (`#855273`) e rosé, transmitindo elegância, seriedade médica e acolhimento.
- **Header Adaptativo:** Navegação fluida no desktop e menu sanduíche responsivo em degradê roxo imersivo no mobile.
- **Hero Seção Otimizada:** Layout focado em conversão, com foto em destaque no mobile, selo circular giratório em CSS e acesso direto ao atendimento.
- **Integração Direta com WhatsApp:** CTAs estrategicamente posicionados com mensagens pré-formatadas para agendamento de exames.
- **Seção "Sobre a Dra." Humanizada:** Espaço dedicado à autoridade médica, trajetória, pós-graduação (`@vmed.pos`) e estatísticas de atendimento.
- **Totalmente Responsivo:** Otimizado de ponta a ponta para smartphones, tablets e desktops.
